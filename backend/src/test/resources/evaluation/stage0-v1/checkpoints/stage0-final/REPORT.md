## 已修复问题

1. 将正常零命中、检索不可用和结构化降级区分为显式状态，阻止语义零命中回退到任意公开房源。
2. 移除 MySQL 无序 `LIMIT 50`，先完成硬条件筛选和全局排序，再截取内部 Top50。
3. 修复 BGE 模型相对路径、ONNX 外部权重和 Maven 实际启动工作目录不一致的问题。
4. 增加 liveness/readiness 分组和 `ragVector` 健康贡献项，检查 VectorStore、Collection、文档数量和 MySQL 同步水位。
5. 通过真实 Chroma 阈值扫描将相似度阈值从 0.50 校准为可配置的 0.58，消除人工确认的特殊设施假推荐。
6. 加固 MySQL 降级评测隔离，测试属性强制关闭 AI/Chroma，不再受开发机 `.env` 影响。

- 当前房源字段仍然稀疏，通勤、楼层、电梯、费用、起租时间、朝向、家电明细等需要阶段 1 建模；本报告不能证明这些未来条件的推荐准确率。
